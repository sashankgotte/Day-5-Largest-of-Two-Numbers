# Day 5 - Largest of Two Numbers

## Description
This Python program finds the largest of two numbers entered by the user.

## Code
```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

print("Largest =", max(a, b))
```

## How It Works
1. The program asks the user to enter the first number.
2. It asks the user to enter the second number.
3. The `int()` function converts the inputs into integers.
4. The `max()` function returns the larger number.
5. The `print()` function displays the result.

## Example Output
```text
Enter first number: 10
Enter second number: 25
Largest = 25
```

## Concepts Covered
- Python input and output
- Integer conversion
- Built-in `max()` function
- Basic arithmetic and comparison concepts

3. Open the terminal.
4. Run `python day5_largest_of_two.py`.
